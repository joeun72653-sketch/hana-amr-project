현재 위치는 AMCL에서 가져오고 목적지를 지도에서 클릭하면 Nav2 경로 미리보기가 자동 계산돼. 같은 경로와 목적지는 RViz의 /amr_web/preview_path · /amr_web/preview_goal에도 표시할 수 있어. 실제 모터 주행은 시작하지 않아.

주행 모드 선택

미리보기 실행에서는 모드만 변경합니다. 실구동 Launch에서는 AUTO 시작 시 안전 인터락을 확인하고 Nav2 목표를 실행합니다.

선택 모드: MANUAL · 실제 제어 미연결

첫 실주행은 좌우 각각 최대 30RPM으로 고정했습니다. 실제 주행 안전 검증 완료 전에는 상향하지 않습니다.

목적지 및 작업 설정

AMR 현재 위치: 대기

ARM 대기 · 안전 조건 확인 필요

실제 주행 제어 비활성 · 모터는 움직이지 않습니다.

실행 상태
